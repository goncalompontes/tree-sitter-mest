# tree-sitter-mest

[Tree-sitter](https://tree-sitter.github.io) grammar for the [Mest](https://github.com/goncalompontes/mestc) programming language.

## Usage

```sh
# Generate parser
npx tree-sitter generate

# Build WASM grammar
npx tree-sitter build --wasm

# Run tests
npx tree-sitter test

# Launch playground
npx tree-sitter playground
```
